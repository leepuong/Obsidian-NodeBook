**Thử tiếp xúc và Thực hành code js trên chrome**
trường hợp bạn sử dụng chrome để code js, đôi lúc bạn sẽ cần code 1 đoạn dài việc này có 2 các để xử lý.
- sử dụng shift + enter: giúp xuống dòng mà không thực thi lập tức đoạn code.
- sử dụng [[Snippet]] 


**Bắt đầu kết hợp js vào html**

**Rồi ra đã có file js cho website của mình, hãy thử lưu trữ nào**
Khởi tạo [[Variable]] và gán giá trị bằng giá trị của hàm [[Prompt()]] và thử in ra.

```js
var a = prompt("input your name here: ");
console.log(a);
```
