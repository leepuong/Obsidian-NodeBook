- **Snippet**: giúp viết code và lưu theo từ file, bạn có thể tìm thấy nó thử ở **Sources -> Snippets -> New snippet**. 
- Để chạy dùng **Ctrl + Enter** hoặc right click vào file chọn **run**
- Để lưu file code lại, bạn có thể Right click vào file chọn **Save as**
