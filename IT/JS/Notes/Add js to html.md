- *Có 2 cách thêm js vào html
###### - **Internal**
```html
	<body>
		<script>
			alert("hello world")
		</script>
	</body>
	```
	+ trước thẻ đóng của thẻ <body>
###### - **External
```html
	<body>
		<script src="./main.js"></script>
	</body>
```
	+ trước thẻ đóng của thẻ <body>
